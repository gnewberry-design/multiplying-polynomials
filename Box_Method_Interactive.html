👨‍🏫 MODEL: How the Box Method Works

Multiply (x + 2)(x + 3). Put one polynomial across the top and one down the side. Each interior cell is the product of its row and column.

×x+3
xx²3x
+22x6

🧩 Add all four cells: x² + 3x + 2x + 6

✅ Combine like terms: x² + 5x + 6

💡 Important: Multiply coefficients and add exponents when multiplying the same variable. For example, (2x²)(−3x) = −6x³.

🌎 Real-World Connection

🏡 A garden has length x + 8 feet and width x + 3 feet. A 2×2 box helps you find its area:

(x + 8)(x + 3) = x² + 11x + 24

📏 If x = 5, the area is 104 square feet.

👻 Common Mistakes to Avoid

🚫 Missing a box: a 2×3 grid must have 6 products.
🚫 Losing a negative sign: negative × positive = negative.
🚫 Multiplying exponents: x² · x³ = x⁵, not x⁶.
🚫 Combining unlike terms: x² and x are not like terms.

🎟️ Exit ticket: Can you explain why multiplying a binomial by a trinomial gives six box entries, even if some combine later?
