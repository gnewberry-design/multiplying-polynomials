  3. 4x² + 3x − x² + 7x = ?
  4. Explain why x² · x³ is not x⁶.
🔎 Check warm-up answers

1) 12x⁵   2) −6x + 10   3) 3x² + 10x   4) Same base: add exponents, giving x⁵.

✨ M — MODEL (I DO) 👨‍🏫

1️⃣ Monomial × Monomial

(3x²)(4x³) = (3 · 4)(x² · x³) = 12x⁵

🔑 Multiply coefficients. Add exponents only when multiplying the same base.

(−2x³y)(5x²y⁴) = −10x⁵y⁵

2️⃣ Monomial × Polynomial

−2x(3x² − 4x + 6)

(−2x)(3x²) + (−2x)(−4x) + (−2x)(6)

✅ −6x³ + 8x² − 12x

3️⃣ Binomial × Binomial: FOIL

(2x − 3)(x + 4)

🥇 First: 2x²   🌈 Outer: +8x   💎 Inner: −3x   🏁 Last: −12

2x² + 8x − 3x − 12

✅ 2x² + 5x − 12

⚠️ FOIL is a memory aid for two binomials only. Distribution and boxes work more generally.

4️⃣ Binomial × Trinomial

(x + 2)(x² + 3x + 4)

x(x² + 3x + 4) + 2(x² + 3x + 4)

x³ + 3x² + 4x + 2x² + 6x + 8

✅ x³ + 5x² + 10x + 8

📦 BOX METHOD — VISUAL MULTIPLICATION

Put one polynomial across the top and the other down the side. Multiply each row header by each column header, then add all the boxes and combine like terms.

🟢 Example A: 2×2 box — (x + 2)(x + 3)

×x+3
xx²3x
+22x6

✅ x² + 3x + 2x + 6 = x² + 5x + 6

🟡 Example B: Negative terms — (2x − 3)(x − 4)

×x−4
2x2x²−8x
−3−3x+12

✅ 2x² − 11x + 12

🟠 Example C: 2×3 box — (x + 2)(x² − 3x + 5)

×x²−3x+5
xx³−3x²5x
+22x²−6x10

✅ x³ − x² − x + 10

🔴 Example D: 3×3 box — (x² + x + 1)(x² − x + 2)

×x²−x+2
x²x⁴−x³2x²
+xx³−x²2x
+1x²−x2

✅ x⁴ + 2x² + x + 2

💡 Degree check: a degree-2 polynomial times a degree-2 polynomial usually has degree 4.

💎 Special Products & Patterns

🌟 Square of a sum: (a + b)² = a² + 2ab + b²

(x + 4)² = x² + 8x + 16

🌟 Square of a difference: (a − b)² = a² − 2ab + b²

(2x − 3)² = 4x² − 12x + 9

🌟 Conjugates / difference of squares: (a + b)(a − b) = a² − b²

(3x + 5)(3x − 5) = 9x² − 25

👻 Remember: (x + 4)² ≠ x² + 16. Don't lose the middle term!

🔍 A — ANALYZE

Compare (x + 3)(x + 3) and (x + 3)(x − 3). Why does one have a middle term while the other does not?

(x + 3)² = x² + 6x + 9

(x + 3)(x − 3) = x² − 9

🧠 In the second expression, −3x and +3x cancel. Both FOIL and a 2×2 box show this.

⚠️ Common mistakes

  • ❌ x² · x³ = x⁶ → ✅ x⁵
  • ❌ 3x(x + 4) = 3x² + 4 → ✅ 3x² + 12x
  • ❌ (x − 2)(x + 5) = x² + 7x + 10 → ✅ x² + 3x − 10
  • ❌ (x + 3)² = x² + 9 → ✅ x² + 6x + 9
  • ❌ Combining x² with x → ✅ Combine only like terms.

🌎 Real-World Application: Garden Area

🏡 A rectangular garden has length (x + 8) feet and width (x + 3) feet.

Area = (x + 8)(x + 3) = x² + 11x + 24 square feet

If x = 5, then the dimensions are 13 feet by 8 feet and the area is 104 square feet.

🧠 Why does the constant term equal 24? It comes from multiplying 8 · 3.
